# Glossaire du drone pour débutants

| Terme | Explication |
|---|---|
| **Accéléromètre** | Capteur qui mesure les accélérations, dont la gravité : il indique où est le bas |
| **AGL** | *Above Ground Level* : hauteur au-dessus du sol |
| **Aileron** | Gouverne au bord de fuite de l'aile ; fait pencher l'avion (roulis) |
| **Allongement** | Envergure² / surface : une aile longue et fine (grand allongement) est plus efficace |
| **ArduPilot** | Logiciel libre de pilotage automatique pour drones, avions, VTOL, bateaux, robots |
| **Armement** | Action qui autorise les moteurs à tourner ; un drone armé est dangereux |
| **Attitude** | Orientation du drone : roulis, tangage, lacet |
| **BEC** | *Battery Eliminator Circuit* : convertisseur qui abaisse la tension pour l'électronique |
| **Bord d'attaque / de fuite** | Avant / arrière de l'aile |
| **Brushless** | Moteur sans balais : rotor à aimants, stator à bobines, piloté par un ESC |
| **C (taux de décharge)** | Courant exprimé en multiple de la capacité : 2 C sur 16 Ah = 32 A |
| **Centre de gravité (CG)** | Point d'équilibre ; doit être à la bonne place pour que l'avion soit stable |
| **Charge alaire** | Masse / surface de l'aile ; plus elle est grande, plus il faut voler vite |
| **Charge utile** | Ce que le drone transporte pour sa mission (caméra, capteur…) |
| **Corde** | Distance entre le bord d'attaque et le bord de fuite |
| **Décrochage** | Perte brutale de portance quand l'aile vole trop lentement ou trop cabrée |
| **Dérive** | Partie verticale de l'empennage ; stabilise en lacet |
| **DShot** | Protocole numérique entre contrôleur de vol et ESC |
| **EKF** | Filtre de Kalman étendu : fusionne les capteurs pour estimer position et attitude |
| **Empennage** | Ensemble stabilisateur à l'arrière (stabilisateur, dérives, gouvernes) |
| **ESC** | Contrôleur électronique de vitesse d'un moteur sans balais |
| **Fail-safe** | Réaction automatique prévue en cas de panne ou de perte de liaison |
| **Finesse** | Portance / traînée ; une finesse de 8,5 signifie 8,5 N portés pour 1 N de traînée |
| **Géorepérage** | *Geofence* : zone virtuelle que le drone ne doit pas quitter |
| **GNSS** | Positionnement par satellites (GPS, Galileo, GLONASS, BeiDou) |
| **Gouverne** | Surface mobile qui dévie l'air pour orienter l'avion |
| **Gyroscope** | Capteur qui mesure la vitesse de rotation |
| **Hélice (diamètre × pas)** | 15 × 5 : 15 pouces de diamètre, 5 pouces d'avance théorique par tour |
| **IMU** | Centrale inertielle : accéléromètres + gyroscopes (+ souvent magnétomètre) |
| **KV** | Tours par minute par volt d'un moteur sans balais, à vide |
| **Lacet** | Rotation autour de l'axe vertical (le nez tourne à gauche ou à droite) |
| **Leurrage (spoofing)** | Faux signaux GPS destinés à tromper la position |
| **LiPo** | Batterie lithium-polymère : légère et puissante, mais à manipuler avec soin |
| **Magnétomètre** | Compas électronique : donne le cap |
| **MAVLink** | Protocole de messages entre drone, station sol et charges utiles |
| **Mission Planner / QGroundControl** | Logiciels de station sol pour ArduPilot |
| **Nacelle (gimbal)** | Support motorisé qui stabilise la caméra |
| **Pitot (tube de)** | Capteur de vitesse par rapport à l'air |
| **Portance** | Force vers le haut produite par l'aile (ou les hélices) |
| **Pre-arm checks** | Vérifications automatiques avant d'autoriser l'armement |
| **Profondeur** | Gouverne horizontale arrière ; fait monter ou descendre le nez (tangage) |
| **Quadplane** | Avion équipé de quatre moteurs verticaux : c'est le SA-1 |
| **Roulis** | Rotation autour de l'axe nez-queue (les ailes penchent) |
| **RSSI** | Indicateur de puissance du signal radio reçu |
| **RTH / RTL** | Retour automatique au point de départ |
| **S (batterie)** | Nombre de cellules en série : 6S = 6 × 3,7 V = 22,2 V |
| **Servomoteur** | Petit moteur qui tient un angle ; actionne les gouvernes |
| **Signature MAVLink** | Signature cryptographique des messages pour rejeter les faux ordres |
| **Stationnaire** | Vol sur place, sans avancer |
| **Tangage** | Rotation autour de l'axe des ailes (le nez monte ou descend) |
| **Télémétrie** | Données envoyées par le drone à la station (position, batterie…) |
| **Télémètre laser** | Capteur de distance au sol |
| **TOPS** | Mille milliards d'opérations par seconde ; puissance d'un accélérateur IA |
| **Traînée** | Résistance de l'air qui freine le drone |
| **Transition** | Passage du vol vertical au vol avion (et inversement) |
| **VLOS** | Vol en vue directe du télépilote |
| **VTOL** | *Vertical Take-Off and Landing* : décollage et atterrissage verticaux |
| **Wh** | Wattheure : énergie ; tension × capacité (22,2 V × 16 Ah = 355 Wh) |
